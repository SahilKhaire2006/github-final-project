# Simple Interest Calculator

A simple Bash script project to calculate simple interest based on user inputs.

## Project Description
This repository contains a simple calculator script that computes simple interest given the principal amount, annual rate of interest, and time period in years.

### Formula Used
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual rate of interest
- **T** = Time period in years

## How to Run
```bash
bash simple-interest.sh
